# AURA Studio 1.2

Локальное all-in-one приложение для Windows: музыкальный плеер, локальный ИИ с
агентами и инструментами, медиа-студия, офлайн-голос, законный OSINT по открытым
источникам, терминал, Python-песочница, управление ПК и LAN-сервер для
Android-клиента.

AURA 1.2 остаётся **local-first**: ИИ, распознавание речи, синтез голоса и рендер
видео выполняются на компьютере. Облачные API-ключи для ИИ не используются.
В интернет приложение выходит только для явно запрошенных действий: публичный
OSINT, GitHub, загрузка модели Vosk, изображения Pollinations, открытые
веб-страницы и поиск, который вы сами открываете в браузере.

## Что нового в 1.2

- Локальные аккаунты в `users.db`: регистрация, вход, роли, отключение и сброс
  пароля администратором, журнал действий.
- Первый зарегистрированный аккаунт становится администратором. Пароли хранятся
  как PBKDF2-HMAC-SHA256 с индивидуальной солью, без открытого текста.
- После входа — выбор рабочего пространства: **Плеер, Песочница, OSINT, ИИ-чат,
  ПК**, а для администратора ещё **Админка**.
- Контекстное меню: в песочнице видны только инструменты песочницы, в OSINT —
  только OSINT, в чате — только ИИ-разделы. Переключатель «Все разделы» остаётся.
- Админ-панель: пользователи, роли, активность, создание, сброс пароля, удаление.
- Отдельная страница **«Управление ПК»**: система, активное окно, процессы,
  скриншот, буфер обмена, медиа-клавиши, окна, питание и запуск приложений.
  Опасные действия проходят через мастер подтверждений.
- Python-редактор: подсветка синтаксиса, подсветка строки ошибки, проверка через
  `ast`, открытие/сохранение `.py`, запуск `Ctrl+Enter` и кнопка
  **«Исправить с ИИ»** с предложением локальной модели.
- Очередь плеера: сохранение очереди как плейлиста и очистка.
- Импорт плейлистов из экспортов Spotify/Яндекс Музыки: CSV с разными названиями
  колонок и вложенный JSON Spotify. Только файловая конвертация, без OAuth,
  scraping и обхода DRM.
- Экспорт плейлиста в JSON для Android/других конвертеров.
- Девять цветовых тем, выбор языка оболочки RU/EN (новые экраны и меню; глубокие
  старые страницы пока остаются на русском).
- OSINT: кнопки поиска в Яндекс/Google/DuckDuckGo и «Сравнить с ИИ»; отчёт
  вставляется в чат, отправку подтверждаете вы.

## Что уже работает

### Аккаунты и рабочие пространства
- Локальная база `%APPDATA%\AURA Studio\users.db`.
- Регистрация первого администратора при пустой базе.
- Вход при каждом запуске; имя пользователя можно запомнить, пароль — нет.
- Роли `admin` и `user`; администратор не может удалить или отключить сам себя,
  а также удалить последнего активного администратора.
- «Сменить пользователя» перезапускает приложение и снова показывает вход.
- Пароли не синхронизируются с облаком. Восстановление возможно только через
  другого администратора; создайте второго администратора заранее.

### Музыка
- Сканирование папок, чтение тегов и обложек (MP3, FLAC, M4A, OGG, WAV, AIFF, WMA).
- Медиатека, поиск, альбомы, исполнители, любимые треки.
- Очередь, перемешивание, повтор одного трека / всей очереди.
- Очередь можно сохранить как новый плейлист или очистить.
- Плеер на pygame/SDL2: пауза, перемотка, громкость, горячие клавиши.
- Плейлисты: создание, переименование, удаление, добавление треков.
- Импорт и экспорт M3U/M3U8, CSV, JSON. Понимаются обычные CSV и экспорты
  Spotify/Яндекс Музыки с колонками `Track Name`, `Artist Name(s)`, `Название`,
  `Исполнитель`, `Ссылка`; Spotify URI превращается в обычную ссылку.
- Шесть демо-треков синтезированы специально для AURA и не содержат чужой музыки.

### Локальный ИИ
- Ollama как единственный провайдер ИИ, без облака и без полей для API-ключей.
- Ровно две управляемые модели: `llama3.2:1b` и `qwen2.5:1.5b`.
- В каждый момент активна только одна: при переключении вторая выгружается.
- Потоковые ответы, температура, история чатов в SQLite.
- Агенты с собственными системными промптами и набором инструментов.
- Навыки в Markdown и Python-плагины.
- Инструменты: музыкальная библиотека и плейлисты, чтение разрешённых файлов,
  запись, терминал, Python-песочница, публичный OSINT, HTTP-запросы, медиа-студия,
  публичный GitHub и управление ПК.
- Каждое опасное действие показывает диалог подтверждения. Доступ к файлам
  ограничен папками, которые вы явно добавили.

### Управление ПК
- Информация о системе, активное окно и список процессов.
- Скриншот всего экрана (сохраняется только в папку AURA).
- Чтение и запись буфера обмена с подтверждением.
- Медиа-клавиши: play/pause, следующий/предыдущий трек, громкость, mute.
- Свернуть, развернуть и закрыть активное окно.
- Блокировка, сон, отмена выключения, перезагрузка/выключение через 20 секунд.
- Открытие URL, папки, документа или приложения.
- Всё выполняется локально, с правами вашей учётной записи Windows и с учётом
  настроек доступа.

### Медиа-студия
- Изображение по текстовому описанию через публичный Pollinations без ключа.
- PPTX через `python-pptx`: титульный слайд, структура, при желании иллюстрации.
- MP4 через локальный ffmpeg: кадры, зумы, переходы, музыка AURA или SAPI-озвучка.
- Результаты сохраняются в `%APPDATA%\AURA Studio\generated` с JSON-метаданными.

### Голос
- Офлайн-распознавание русской речи Vosk; аудио не загружается в облако.
- Озвучка Windows SAPI, выбор установленного голоса.
- Голосовые команды: навигация, музыка, громкость, поиск, запуск разрешённых
  приложений, открытие сайтов и папок, вопросы к ИИ.
- Включение микрофона кнопкой или `Ctrl+Shift+V`; действия с ПК проходят через
  мастер-разрешения и подтверждение.

### OSINT (только законные публичные источники)
- Домен: DNS, MX, TXT, NS, RDAP/WHOIS, TLS-сертификат, HTTP-заголовки, crt.sh.
- IP: geo/ASN по публичным API, обратный DNS, RDAP, Shodan InternetDB.
- Публичные профили по username: GitHub, GitLab, Reddit, Telegram, YouTube,
  SoundCloud и другие площадки.
- Email: публичный Gravatar и MX-записи домена; без баз утечек.
- Компания: GLEIF и SEC EDGAR; GitHub — публичные профили и репозитории.
- Открытие поиска в Яндекс/Google/DuckDuckGo в браузере.
- Кнопка «Сравнить с ИИ» вставляет отчёт в локальный чат; ИИ помогает найти
  совпадения и противоречия, но не заменяет проверку первоисточников.
- Отчёты можно копировать и сохранять в текст.

Чего здесь нет и не будет: пробива по номеру телефона, ФИО, адресу, паспорту,
СНИЛС, поиска приватных аккаунтов, данных из утечек, платных/закрытых баз,
деанонимизации и обхода ограничений сервисов. Это осознанная граница законного
инструмента.

### Терминал и Python-песочница
- PowerShell внутри приложения с историей команд, сменой папки и копированием.
- Python-редактор с подсветкой синтаксиса и строкой ошибки.
- Проверка синтаксиса через `ast`, открытие и сохранение `.py`.
- Запуск `Ctrl+Enter`; после ошибки доступна кнопка «Исправить с ИИ». Локальная
  модель предлагает код, но применить его можно только после просмотра.
- Песочница: Docker без сети, если Docker установлен; иначе локальный Python с
  временным каталогом и таймаутом. Локальный режим **не** изолирует память и сеть —
  это указано в интерфейсе.
- Терминал, запись и песочница доступны только после включения в настройках.

### Локальный сервер и Android
- FastAPI-сервер на ПК: `/mobile`, чат, медиатека, плейлисты, обложки,
  потоковое аудио с поддержкой Range, лайки.
- Авторизация по случайному токену; по умолчанию сервер слушает `127.0.0.1`.
- LAN-режим включается отдельно.
- Мобильный веб-клиент: чат с агентами, поиск, плейлисты, плеер, Media Session.
- Android-приложение — WebView-клиент к серверу AURA. Оно не запускает локальный
  ИИ на телефоне и не получает доступ к файлам Android.
- Аккаунты AURA 1.2 — это локальные аккаунты Windows-приложения; мобильный клиент
  по-прежнему использует LAN-токен сервера.

## Быстрый старт (Windows)

1. Установите Python 3.11–3.13 (галочка «Add Python to PATH»).
2. Установите [Ollama](https://ollama.com/download) и загрузите модели:
   ```powershell
   ollama pull llama3.2:1b
   ollama pull qwen2.5:1.5b
   ```
3. В папке проекта:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python app.py
   ```
4. При первом запуске зарегистрируйте администратора. Затем выберите рабочее
   пространство: плеер, песочницу, OSINT, ИИ-чат или ПК.
5. Откройте «Коллекция»: демо-треки появятся автоматически, либо добавьте папку.
6. «Настройки → Локальный ИИ»: выберите модель и нажмите «Активировать».
7. Для голоса откройте «Голос» и скачайте модель Vosk (около 45 МБ).
8. Для Android включите «Настройки → Сервер → LAN», запустите сервер и введите
   адрес с токеном в мобильном приложении.

Данные пользователя по умолчанию: `%APPDATA%\AURA Studio`
(`settings.json`, `aura.db`, `users.db`, `vault.bin`, `covers`, `workspace`,
`agents`, `skills`, `plugins`, `generated`, `logs`). Каталог можно изменить
переменной `AURA_DATA_DIR` или ключом `--data-dir`.

## Сборка EXE

```powershell
.\build_exe.ps1
```

Скрипт установит зависимости, соберёт `dist\AURA\AURA.exe` и упакует
`dist\AURA-Studio-1.2.0-Windows-x64.zip`. Если APK уже собран, он будет
скопирован в `dist\AURA-Mobile-1.2.0-debug.apk`. Для одного файла:

```powershell
.\build_exe.ps1 -OneFile
```

Однофайловая сборка стартует медленнее (распаковка во временный каталог), но
удобнее для передачи. Папка `dist\AURA` запускается быстрее.

> EXE не подписан сертификатом. SmartScreen может показать предупреждение —
> это нормально для локально собранного приложения. Подпись требует вашего
> собственного сертификата Code Signing.

## Сборка APK

Исходники: `mobile_android/`. Проект собран с JDK 17, Android SDK 34 и Gradle 8.7.

```powershell
cd mobile_android
.\gradlew.bat assembleDebug
# app\build\outputs\apk\debug\app-debug.apk
```

Нужны JDK 17 и Android SDK 34 (переменная `ANDROID_HOME`). Если проект лежит
в пути с кириллицей, в `gradle.properties` уже включён
`android.overridePathCheck=true`.

Требования к Android: 7.0+ (minSdk 24), доступ к локальной сети, разрешение
HTTP для `http://` адресов (`usesCleartextTraffic`). Токен хранится в приватных
настройках приложения, резервное копирование отключено (`allowBackup=false`).

APK собран в debug-подписи. Для публикации в Google Play нужен собственный
release-ключ и подпись. Готовый APK ещё не проверялся на физическом устройстве
или эмуляторе — это ограничение текущей сборки, а не заявление о совместимости.

## Две локальные модели

| Модель | Размер | Назначение | Ограничение |
|---|---:|---|---|
| `llama3.2:1b` | ~1,3 ГБ | быстрые ответы и вызов инструментов | слабая логика; один инструмент за запрос |
| `qwen2.5:1.5b` | ~1,0 ГБ | русский текст и пересказ | может не вызывать инструменты |

Модели взаимоисключающие: AURA выгружает неактивную через Ollama API и прогревает
выбранную. Другие модели, установленные в Ollama, AURA не трогает и не показывает.

Малые модели не заменяют большие облачные модели. Они полезны для локальных
команд, кратких ответов и работы с медиатекой, но могут ошибаться в сложных
рассуждениях. Для инструментов малой модели AURA возвращает фактический результат
инструмента напрямую, чтобы избежать повторения JSON-схем.

## GitHub

- Публичные профили, репозитории и поиск работают без токена.
- Для приватных репозиториев, push и `gh`-команд нужен официальный GitHub CLI.
- AURA умеет скачать портативный `gh.exe` в `%APPDATA%\AURA Studio\github-cli`.
- Вход выполняется только интерактивно через `gh auth login` в отдельном окне.
  Приложение не хранит пароль GitHub и не просит токен вручную.

## Тесты

```powershell
python scripts\smoke_auth.py
python scripts\smoke_core.py
python scripts\smoke_terminal.py
python scripts\smoke_player.py
python scripts\smoke_server.py
python scripts\smoke_ui.py
python scripts\smoke_voice.py
python app.py --smoke-test
python app.py --smoke-media --data-dir "$env:TEMP\aura-media-smoke"
```

Скрипты используют временные каталоги данных и не трогают вашу медиатеку.
`smoke_auth.py` проверяет регистрацию, роли, запрет самоблокировки и UI админки.
`smoke_ui.py` запускается в offscreen-режиме. `--smoke-media` проверяет PPTX,
ffmpeg-видео, TTS и Vosk без сети и пишет отчёт в `smoke-media.json`. Голосовой
smoke-тест проверяет маршрутизатор команд и TTS; распознавание живой речи требует
отдельной проверки с микрофоном.

## Безопасность и ограничения

- Локальные аккаунты защищают от случайного доступа за этим компьютером, но не
  заменяют пароль Windows, BitLocker и физическую безопасность. Любой, кто имеет
  доступ к вашей учётной записи Windows и файлам `%APPDATA%`, может прочитать
  локальную базу.
- Пароли хранятся как PBKDF2-HMAC-SHA256 (260 000 итераций) с индивидуальной
  солью. Восстановления по email нет. Если единственный администратор забыл
  пароль, автоматического сброса нет — создайте второго администратора заранее.
- Терминал выполняет команды с правами вашей учётной записи Windows. Это не
  песочница; включайте его только если понимаете риск.
- Локальная Python-песочница без Docker не изолирует сеть и память.
- ИИ не получает доступ ко всему диску: только к папкам из списка доступа.
  Запись, терминал, песочница, сеть, OSINT и действия с ПК требуют подтверждения.
- Сервер по умолчанию доступен только с этого компьютера. LAN-режим открывает
  его в локальной сети; не пробрасывайте порт в интернет без VPN/обратного прокси.
- Токен LAN хранится зашифрованным, но любой, кто получил доступ к вашей учётной
  записи Windows, может расшифровать vault. Защитите учётную запись.
- Pollinations работает без ключа, но ограничивает частоту. При HTTP 402/429
  AURA показывает понятную ошибку. Внешний лимит не обходится и не выдаётся за
  успешную генерацию.
- Публичный GitHub API имеет собственные лимиты. Приватные операции требуют
  `gh auth login` и выполняются официальным CLI.
- Spotify: облачная интеграция и OAuth не используются. AURA не скачивает
  потоковое аудио и не обходит DRM; используйте экспорт/импорт M3U/CSV/JSON и
  внешние ссылки.
- Яндекс Музыка не имеет официального публичного API для сторонних плееров,
  поэтому поддерживается только файловый импорт/экспорт.
- **YandexGPT API не добавлен**: для него нужны ключ и folder ID Yandex Cloud,
  а также отдельный облачный режим. AURA 1.2 остаётся local-first и не хранит
  облачные ИИ-ключи. Кнопки «Яндекс» и «Google» открывают обычный поиск в
  браузере; AURA не scraping-ит выдачу и не обходит CAPTCHA.
- Android-клиент — это LAN-клиент, а не автономное приложение с локальным ИИ.
  Локальные аккаунты 1.2 относятся к Windows-приложению; мобильный вход остаётся
  по LAN-токену.
- Распознавание живой речи и установка APK на физическое устройство ещё требуют
  проверки на конкретном оборудовании.
- Приложение не выполняет «пробив» по телефону, ФИО или иным персональным данным,
  не использует утечки, закрытые базы и деанонимизацию.
- Язык RU/EN в 1.2 переключает оболочку, вход, workspace, админку и страницу ПК.
  Глубокие старые страницы (медиатека, настройки, студия) пока содержат русский
  текст; это ограничение, а не полная локализация.
